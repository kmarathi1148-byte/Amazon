🛒 Dashboard Overview

This project is an interactive Amazon Sales Analysis Dashboard created using Tableau. It analyzes Amazon sales data to identify sales trends, product performance, customer orders, and category-wise insights.

Dashboard Objective

The main objective of this project is to analyze Amazon sales data and identify useful trends and patterns through interactive data visualization.

Dashboard Features

- Interactive visualizations
- Monthly sales trend analysis
- Category-wise sales comparison
- Order status analysis
- Category sales pie chart
- Fulfillment analysis
- State-wise sales visualization using maps
- Top 10 product analysis
- Easy-to-understand visual representation of sales data

Key Insights

- Monthly sales show noticeable variations across different months.
- Sales performance differs across product categories.
- The dashboard highlights the top-performing product categories.
- Order status analysis helps understand successful and pending orders.
- Fulfillment analysis compares Amazon and Merchant fulfillment.
- State-wise analysis shows the geographical distribution of sales.
- The Top 10 Products chart identifies products contributing significantly to sales.
